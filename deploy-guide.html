Deployment Guide

Complete instructions for deploying the MobileWise AI Trigger System to client websites

🚀 Quick Start - 5 Minutes

Just need the embed code? Here's what to give your clients:

<!-- Add before closing </body> tag -->
<script>
  window.MobileWiseWidgetConfig = {
    clientId: "CLIENT_ID_FROM_DASHBOARD",
    buttonColor: "#4361ee",
    serverUrl: "https://your-server.com"
  };
</script>
<script src="https://your-server.com/js/client-website-widget.js"></script>

Replace your-server.com with your actual server URL

1

📦 File Structure & Setup

Upload these files to your web server:

Required Files

/ (root directory)
widget-dashboard.html
trigger-control-system.html
/js
client-website-widget.js
/configs (optional)
widget-config-[client-id].json
2

⚙️ Configure Your First Client

Use the Widget Dashboard to set up client configurations:

Essential Configuration

Client Name: Business name (e.g., "Mortgage Assist")

Agent ID: From LemonSlice dashboard (starts with "agent_")

Trigger Phrases: What Bohemia should listen for

Example: Mortgage Assist Client

  • Agent ID: agent_1db77d60ec132469
  • Widget Color: #4361ee (blue)
  • Testimonial Triggers: "results, pricing, testimonials"
  • Video Triggers: "product video, how to, tutorial"
  • Auto-welcome: "Hi! I'm your mortgage AI assistant..."
3

🔧 Create Client Embed Code

Generate the embed code for each client after configuration:

<!-- Embed Code for: Mortgage Assist -->
<script>
  window.MobileWiseWidgetConfig = {
    clientId: "mortgage-assist", // From dashboard
    buttonColor: "#4361ee", // Match client brand
    serverUrl: "https://your-server.com", // Your server URL
    autoOpen: false, // Don't auto-open widget
    position: "bottom-right" // bottom-left, bottom-right
  };
</script>
<script src="https://your-server.com/js/client-website-widget.js"></script>

Important Security Note

Always use HTTPS for production. Update your-server.com to your actual domain.

4

🌐 Deploy to Client Website

Add the embed code to the client's website:

Where to Place the Code

Best: Just before the closing </body> tag

Alternative: In the website footer or global scripts

Avoid: Inside iframes or restricted areas

Client Website Integration

<!-- Client website HTML -->
<!DOCTYPE html>
<html>
<head>
    <title>Client Website</title>
    <!-- Other head elements -->
</head>
<body>
    
    <!-- Website content here -->
    
    <!-- ADD MOBILEWISE AI WIDGET HERE -->
    <script>
      window.MobileWiseWidgetConfig = {
        clientId: "mortgage-assist",
        buttonColor: "#4361ee",
        serverUrl: "https://your-server.com"
      };
    </script>
    <script src="https://your-server.com/js/client-website-widget.js"></script>
    
</body>
</html>
5

🎯 Testing & Verification

Verify the system is working correctly:

  • Widget appears on client website (floating button)
  • Clicking button opens Trigger Control System
  • Bohemia widget loads with correct agent
  • Audio detection works (status shows "active")
  • Trigger phrases work (say "show me testimonials")
  • Modules launch when triggers detected

Troubleshooting Tips

Widget not appearing? Check JavaScript console for errors

Bohemia not loading? Verify Agent ID is correct

Triggers not working? Check microphone permissions

No audio detection? Ensure browser supports Web Audio API

client-website-widget.js

(function() {
    'use strict';
    
    class MobileWiseTriggerWidget {
        constructor(config) {
            this.config = {
                clientId: 'default-client',
                buttonColor: '#4361ee',
                serverUrl: window.location.origin,
                autoOpen: false,
                position: 'bottom-right',
                ...config
            };
            
            this.controlPanelWindow = null;
            this.init();
        }
        
        init() {
            // Add styles
            this.addStyles();
            
            // Create floating button
            this.createButton();
            
            console.log('🚀 MobileWise Trigger Widget Initialized');
        }
        
        addStyles() {
            const style = document.createElement('style');
            style.textContent = `
                #mw-trigger-button {
                    position: fixed;
                    bottom: 30px;
                    right: 30px;
                    background: ${this.config.buttonColor};
                    color: white;
                    padding: 16px 28px;
                    border-radius: 30px;
                    cursor: pointer;
                    box-shadow: 0 8px 30px rgba(0,0,0,0.3);
                    z-index: 99999;
                    display: flex;
                    align-items: center;
                    gap: 12px;
                    font-family: 'Inter', sans-serif;
                    font-weight: 600;
                    font-size: 16px;
                    border: none;
                    transition: all 0.3s;
                }
                
                #mw-trigger-button:hover {
                    transform: scale(1.05);
                    box-shadow: 0 12px 40px rgba(0,0,0,0.4);
                }
                
                #mw-trigger-button i {
                    font-size: 20px;
                }
                
                .mw-module-container {
                    position: fixed;
                    top: 50%;
                    left: 50%;
                    transform: translate(-50%, -50%);
                    background: white;
                    border-radius: 20px;
                    box-shadow: 0 40px 100px rgba(0,0,0,0.5);
                    z-index: 99998;
                    max-width: 900px;
                    width: 95%;
                    animation: mw-scaleIn 0.4s ease;
                }
                
                @keyframes mw-scaleIn {
                    from { transform: translate(-50%, -50%) scale(0.9); opacity: 0; }
                    to { transform: translate(-50%, -50%) scale(1); opacity: 1; }
                }
            `;
            document.head.appendChild(style);
        }
        
        createButton() {
            const button = document.createElement('button');
            button.id = 'mw-trigger-button';
            button.innerHTML = `
                
                AI Guide Assist
            `;
            
            button.addEventListener('click', () => this.openControlPanel());
            
            // Add Font Awesome
            this.addFontAwesome();
            
            // Add to page
            setTimeout(() => {
                document.body.appendChild(button);
            }, 1000);
        }
        
        addFontAwesome() {
            if (!document.querySelector('link[href*="font-awesome"]')) {
                const link = document.createElement('link');
                link.rel = 'stylesheet';
                link.href = 'https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css';
                document.head.appendChild(link);
            }
        }
        
        openControlPanel() {
            if (this.controlPanelWindow && !this.controlPanelWindow.closed) {
                this.controlPanelWindow.focus();
                return;
            }
            
            // Open control system
            const url = `${this.config.serverUrl}/trigger-control-system.html?client=${this.config.clientId}`;
            this.controlPanelWindow = window.open(
                url, 
                'MobileWiseAI',
                'width=1400,height=900,menubar=no,toolbar=no,location=no,status=no'
            );
            
            // Listen for messages
            window.addEventListener('message', this.handleMessage.bind(this));
        }
        
        handleMessage(event) {
            // Security check
            if (event.origin !== this.config.serverUrl) return;
            
            const data = event.data;
            
            switch(data.type) {
                case 'MODULE_TRIGGERED':
                    console.log('🎬 Module triggered:', data.module);
                    this.displayModuleOnSite(data);
                    break;
                    
                case 'CLOSE_CONTROL_PANEL':
                    if (this.controlPanelWindow) {
                        this.controlPanelWindow.close();
                        this.controlPanelWindow = null;
                    }
                    break;
            }
        }
        
        displayModuleOnSite(data) {
            // Remove existing module
            const existing = document.querySelector('.mw-module-container');
            if (existing) existing.remove();
            
            // Create new module container
            const container = document.createElement('div');
            container.className = 'mw-module-container';
            
            const moduleTitles = {
                'testimonial': '🎬 Client Testimonial',
                'videoVault': '📹 Video Demonstration', 
                'communication': '💬 Communication Hub',
                'websiteInfo': '🌐 Website Navigation'
            };
            
            container.innerHTML = `
                

                    

                        

                            ${moduleTitles[data.module] || 'AI Content'}
                        

                        
                    

                    
                    

                        

                            Triggered by AI conversation: "${data.triggerPhrase || 'Unknown phrase'}"
                        

                        
                        

                            
${this.getModuleTitle(data.module)} Ready

                            
Your content is ready to display...

                            ${this.getModuleActionButton(data.module)}
                        

                    

                

            `;
            
            document.body.appendChild(container);
            
            // Auto-remove after 5 minutes
            setTimeout(() => {
                if (container.parentElement) {
                    container.remove();
                }
            }, 300000);
        }
        
        getModuleTitle(moduleName) {
            const titles = {
                'testimonial': 'Testimonial Player',
                'videoVault': 'Video Gallery',
                'communication': 'Communication Hub',
                'websiteInfo': 'Website Navigation'
            };
            return titles[moduleName] || 'Content';
        }
        
        getModuleActionButton(moduleName) {
            const buttons = {
                'testimonial': `
                    
                `,
                'videoVault': `
                    
                `,
                'communication': `
                    
                `,
                'websiteInfo': `
                    
                `
            };
            return buttons[moduleName] || '';
        }
        
        // Public API
        open() {
            this.openControlPanel();
        }
        
        close() {
            if (this.controlPanelWindow) {
                this.controlPanelWindow.close();
                this.controlPanelWindow = null;
            }
        }
    }
    
    // Auto-initialize if config provided
    if (window.MobileWiseWidgetConfig) {
        window.MobileWiseWidget = new MobileWiseTriggerWidget(window.MobileWiseWidgetConfig);
    }
    
    // Global access
    window.MobileWiseTriggerWidget = MobileWiseTriggerWidget;
    
    console.log('📦 MobileWise Trigger Widget Loaded');
})();
